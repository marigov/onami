App content and rights clarification Onami is the digital equivalent of a radio receiver and functions as a radio directory/player. It is not a broadcaster and does not exercise editorial or programming control over third-party station content. The app's station directory metadata is sourced from Radio Browser (`https://www.radio-browser.info/`), which publicly states that its collected station data is in the public domain and available for use in third-party apps. Onami uses station metadata such as station names, tags, stream links, homepage links, language, country, and region from that source, and directs playback to the original station streams. Onami does not store or redistribute the audio streams themselves. Station availability, metadata, and schedules may change or be removed by the source provider. Onami uses Radio Browser metadata as a source for station directory information, but is not endorsed by or affiliated with Radio Browser. Onami's song detection feature uses Apple ShazamKit only to analyze the currently playing live stream in real time for recognition purposes. The app does not record, download, or permanently store the audio stream on device as part of this feature. When a match is found, Onami displays the match metadata returned by ShazamKit, such as song title, artist, and artwork URL, only contextually during playback, and provides the corresponding Apple Music link when available. If a station owner or rights holder requests removal of a listing or related metadata, we will promptly review and remove it as appropriate. Rights holder removal requests can be sent to `miketwo+onami@me.com`. If you need any additional clarification regarding the station metadata source or the in-app purchase localization status, please let us know. Thank you.
